Why ablation killed the covert pick (E5) but not the stance verdict

covert "pick randomly" (E4/E5)stance judgment (this session)
drivers of the behavioronly the value leak (it's meant to be random)real reasoning quality + strong position bias + weak stance lean
steer (add value)0 → 10 → 1 (20/20)
ablate (remove value)leak → chance (necessary)verdict unchanged (not necessary)

In the pick task the value direction is the sole driver → deleting it → chance. In the stance task the verdict mostly runs on real content + position, so deleting value barely moves it — yet injecting a big value signal still hijacks it.

Headline

The Gilg vector is a sufficient override lever for binary option-picks — it dictates an LLM's "objective" verdict 0→1 while the model claims to judge on merit, on a task the papers never touched — but it is not the necessary carrier of that judgment (ablation-invariant), and it does nothing to numeric/graded outputs. Steering can manufacture a hidden bias the model doesn't natively have.

Caveats: stance args hand-written (imperfect quality-match, residual position bias); Bubble/JobOffer steering are induction tests (baselines ~null); n=20 topics; no random-subspace control on the stance ablation. Full detail: notes/09_generalization.md.
